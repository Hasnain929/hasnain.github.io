# Hasnain Qureshi — Animated Portfolio

A responsive, dark-theme portfolio website made with HTML, CSS and JavaScript. It is ready for GitHub Pages.

## 1. Personal details to update

Open `index.html` and replace these placeholders:

- `hasnainazad929@gmail.com` with your real email address.
- `923164384336` in the WhatsApp link with your WhatsApp number (country code, no `+`).
- Add your CV PDF at `assets/cv.pdf` (keep the exact filename `cv.pdf`).
- Replace the sample project cards with your real project names, descriptions, links and screenshots.

## 2. Publish on GitHub Pages

1. Create a GitHub repository. For a user site, the repository name should be `YOUR-USERNAME.github.io`.
2. Upload **all files inside this folder** to the repository root (not the ZIP file).
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait a few minutes and open the URL shown in the Pages section.

If you are using an existing repository, upload these files to that repository and use its Pages URL.

## 3. Files

- `index.html` — page content
- `style.css` — design, responsive layout and animations
- `script.js` — preloader, scroll reveal, mobile menu and motion effects
- `assets/` — add your CV and any local images here
